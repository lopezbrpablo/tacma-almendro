# Datos experimentales

El archivo [`caso1.RData`](caso1.RData) contiene los datos utilizados en el **TACMA Caso 1** sobre incidencia de una enfermedad fúngica en hojas de almendro.

Cada observación corresponde a una planta. El conjunto registra el número de hojas dañadas y evaluadas, así como las condiciones experimentales de temperatura, humectación, aislado y réplica.

La incidencia observada se define como `damaged_leaves / total_leaves`.

La descripción de las variables y de los modelos utilizados se encuentra en [`../codigo/README.md`](../codigo/README.md).
